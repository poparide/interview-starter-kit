# Poparide frontend interview

Thanks for interviewing with us. Before we meet, please get this project running
on your phone or your laptop, so we can make the most of our time together.

## Setup

- Clone this repo
- Install **Node.js 24** (`nvm use` reads `.nvmrc`)
- Install **Expo Go** on your phone
- **iPhone only:** create a free account at [expo.dev](https://expo.dev), sign
  in to it in Expo Go, and run `npx expo login` in `apps/mobile` with the same
  account
- From the repo root, run `npm install`

## Run

- From `apps/mobile`, run `npm start`
- Your phone must be on the same Wi-Fi as your computer
- **iPhone:** scan the QR code with the Camera app, or open the project under
  "Development servers" in Expo Go
- **Android:** scan the QR code in Expo Go
- If something looks stale, reload with `r`, or restart with
  `npx expo start -c` to clear the cache

## Check it works

You should see a screen that says "Hello Poparide". If you do, you're ready. If
something doesn't work, let us know before the interview and we'll help.

## Optional: simulator or emulator

If you'd rather not use your phone, you can use the iOS Simulator (needs Xcode)
or an Android emulator (needs Android Studio).
